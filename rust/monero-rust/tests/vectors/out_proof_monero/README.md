# OutProofV2 compatibility vectors

`out_proof_v2.json` contains proofs generated by Monero's `crypto::generate_tx_proof`
at commit `d0d418483`. The harness checks each proof with `crypto::check_tx_proof(..., 2)`
before writing it. `tests/tx_proof_test.rs` verifies these proofs with the Rust implementation.

Each case also includes a recorded `rust_signature` generated from the same inputs and
accepted by Monero. Fresh signatures use random nonces, so their bytes will differ.

The cases cover standard addresses and subaddresses, with empty and nonempty messages.
Subaddress proofs use B as the generator for X and R; standard-address proofs use G and
zero the B field in the challenge.

## Regenerate the vectors

`harness.cpp` links against a built Monero source tree. It calls the crypto functions
directly and needs no running daemon or wallet. From this directory:

```sh
export MONERO_SRC=~/src/monero/monero        # build.sh's default source directory
export MONERO_BUILD=$MONERO_SRC/build/Linux/master/release
sh build.sh ./harness
./harness gen > out_proof_v2.json
```

The generated JSON omits the `source` metadata and recorded `rust_signature` fields.
Restore the metadata and capture fresh Rust signatures before replacing the fixture.

To generate Rust proofs, run this from the Rust workspace:

```sh
cargo test -p monero-rust --test tx_proof_test -- --ignored --nocapture emit_proofs
```

From the harness directory, pass each printed argument list to `./harness check`.
It prints `VALID` or `INVALID`. Record each accepted signature in the corresponding case.
